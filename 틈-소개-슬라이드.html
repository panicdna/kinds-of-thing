틈TEUM · A LITTLE RESET

몰입하는 시간 사이, 나를 돌보는 작은 틈.
정해진 간격으로 전체 화면 쉼을 띄워 주는 PC 알림기입니다.

v1.2.1 · 2026-11-12 · github.com/panicdna/kinds-of-thing

WHY

열심히 일하다 보면, 몸이 먼저 굳어 있습니다

틈은 "쉬세요"라는 잔소리가 아니라, 이미 내가 고른 방식으로 잠깐 화면을 비워 주는 도구예요.

문제

집중에 빠지면 시간이 사라져요. 2시간 뒤 목·허리·손목이 먼저 신호를 보내지만, 문서와 회의 틈에 그 신호를 계속 미루게 됩니다.

틈의 답

정한 시각에 전체 화면이 떠서 "지금이 쉼"을 알려 주고, 스트레칭·명상·영상 중 내가 고른 하나를 보여 준 뒤 닫으면 사라져요. 기록도, 평가도 없습니다.

틈 TEUM · v1.2.12
FEATURES

네 가지 핵심

① 고정 시각표 알림

09:00 시작 · 60분 간격이면 10:00, 11:00… 정각에 떠요. 늦게 닫아도 시각표가 밀리지 않고, 놓친 알림을 몰아서 띄우지 않아요.

② 내가 고르는 쉼

스트레칭 GIF, 명상, 발성, 릴렉스 영상, 안무, 요리까지. 무엇을 볼지는 언제나 사용자가 정해요.

③ 알아서 쉬는 알림

점심 시간, 자리비움(입력 없음), 화면 잠금·절전 중에는 알림이 스스로 멈춰요. 몰아치기가 없습니다.

④ 프라이버시 우선

계정·마이크·카메라 없이 PC 안에서만 동작. 설정은 %LOCALAPPDATA%에 저장돼요. (사내 Knox 일정 연동은 선택 사항)

설치 30초

인스톨러 하나, 관리자 권한 불필요. 설치만으로 합리적인 기본 프리셋이 적용돼요.

무중단 업그레이드

v1.2.1 인스톨러는 실행 중인 앱도 자동 종료 후 재설치해요. 사용자 카드는 지켜요.

INSTALL

설치는 30초

  • Teum-Setup-v1.2.1.exe 실행
    관리자 권한 불필요 · 사용자 폴더(%LOCALAPPDATA%\Programs\틈)에 설치
  • 마지막 화면 "틈 실행" 체크 후 완료
    트레이에 아이콘이 생기고 백그라운드로 시작
  • 트레이 아이콘 더블클릭 → 설정 창
    왼쪽 위 Head Title에 v1.2.1 표시로 버전 확인
  • 다음 날 아침부터 알림 시작
    기본 프리셋이 이미 적용돼 있어요 →

UX SCENARIO ①

하루가 이렇게 흘러요

  • 09:00로그인과 함께 틈이 시작 — 트레이에만 있고, 화면은 조용해요. 상태: "알림 대기 중"
  • 10:00첫 쉼 — 전체 화면에 카드 하나가 떠요(예: 앉아서 스트레칭). Esc나 닫기 ×로 닫으면 다음 시각까지 대기
  • 11:00다음 쉼 — 무작위 모드라면 이번엔 명상. 왼쪽 "다음 작은 쉼" 목록에 앞으로 뜰 시각이 미리 보여요
  • 12:00점심 — 알림이 알아서 쉬어요 — 12:00–13:00 쉬는 시간. 걸린 알림은 13:00으로 미뤄집니다
  • 17:00퇴근버스 카드 — 반복 시각표와 별개로 하루 한 번, 퇴근길 영상이 떠요
  • 18:00근무 종료 — 알림도 퇴근 — 18:00 이후·주말·화면 잠금 중에는 뜨지 않아요

UX SCENARIO ③

회의 시작 전에도, 틈이 먼저

  • 15분 주기로 Knox 캘린더 자동 가져오기 — "지금 일정 가져오기 ↻"로 즉시 확인도 가능
  • 회의 5분 전(조절 가능) 전체 화면 알림 — 회의 제목·시간 + 종소리 영상 하나
  • 자동 닫힘 선택 — 없음 / 시작시간에 / 시작후 N분 / 끝난시간에. 자리비움 자동 닫기의 영향을 받지 않아요
  • 알림 시험 버튼 — 실제 팝업을 바로 띄워 미리 볼 수 있어요

주의 · Knox ID 등록

틈은 Windows 로그인 계정 이름으로 일정 서버에 조회해요. "Knox ID가 등록돼 있지 않습니다" 안내가 뜨면 앱 문제가 아니라 서버 화이트리스트에 ID가 없는 것 — 관리자에게 등록을 요청하세요.

사내망에서만 동작 · 일정 데이터는 이 PC의 %LOCALAPPDATA%에만 씁니다

틈 TEUM · v1.2.17
UX SCENARIO ④

사용자가 없을 때, 알림도 쉬어요

점심 12–13시

쉬는 시간에 걸린 알림은 끝나는 시각(13:00)으로 한 번만 미뤄져요.

자리비움 10분

입력이 없으면 상태가 "입력 없어서 잠김". 열려 있던 쉼 창도 자동으로 닫혀요(일정 알림 제외). 돌아오면 1번 떠서 재개를 알려요.

화면 잠금·절전

알림을 완전히 멈추고, 깨어난 뒤 다음 고정 시각부터 이어갑니다. 몰아치기 없음.

설계 원칙: 틈은 결코 잔소리하지 않아요. 미뤄진 알림을 몰아서 띄우거나, 닫기를 강요하거나, 자동으로 사라지지 않아요. (일정 알림 자동 닫힘은 사용자가 직접 선택한 경우만)

SAFETY & PRIVACY

조심스러운 분야는, 조심스럽게

안전 원칙

· 일반 휴식 안내이며 치료·재활 처방·자세 교정 효과를 보장하지 않아요
· 통증 증가·저림·어지럼 즉시 중지. 레드 플래그(다리 힘 빠짐·감각 이상·대소변 조절 변화)는 즉시 진료
· 안무는 서서 하는 원본 — 공간 확인, 통증 있으면 저강도 카드로
· GIF는 이해용 미리보기, 속도를 따라 하지 않아도 돼요

데이터 원칙

· 계정·마이크·카메라 없음 · 입력값 외부 전송 없음
· 설정·카드: %LOCALAPPDATA%\DeskHooker (재설치에도 사용자 카드는 유지)
· 외부 연결은 2가지만: 카드의 YouTube 영상, 사내 Knox 일정 조회(선택)
