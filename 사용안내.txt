틈 / DeskHooker
내 PC에서 실행하는 주제별 휴식 알림기

실행
  C:\work\desk-stretch\DeskHooker.exe를 두 번 클릭합니다.
  간격(1~240분), 실행 요일·시간, 주제를 고른 뒤 '알림 시작'을 누릅니다.
  기본 표시값은 60분, 평일 09:00부터 18:00 전까지입니다.
  처음 실행할 때는 사용자가 시작하기 전까지 반복 알림을 켜지 않습니다.

창과 알림의 관계
  주제가 전체 화면에 표시됩니다. 팝업은 자동으로 닫히지 않습니다.
  팝업의 '닫기' 또는 Esc를 누르면 그 팝업만 닫힙니다.
  팝업을 닫은 시점부터 선택한 간격을 다시 계산합니다.
  설정 창의 X는 트레이로 숨깁니다. 백그라운드 알림은 계속됩니다.
  종료하려면 트레이 메뉴 또는 설정 창에서 '알림기 완전히 종료'를 누릅니다.
  간격은 설정 창을 다시 열어 언제든 변경할 수 있습니다.
  Windows 자동 시작은 사용자가 체크한 경우에만 등록합니다.
  잠금·절전 중에는 표시하지 않습니다. 돌아온 뒤 놓친 알림을 몰아 띄우지 않습니다.

주제
  스트레칭, 명상, 의자 필라테스 기초, 가벼운 코어,
  호흡, 발성, 앉아서 허리 자세 바꾸기, 의자를 짚고 일어나기,
  공식 걸그룹 안무 영상, 시 한 줄 채우기.
  여러 주제를 고르면 화면의 목록 순서대로 번갈아 표시합니다.

호흡·발성
  GIF는 동작 미리보기이며 강제로 따라야 하는 속도가 아닙니다.
  타이머는 사용자가 '가이드 시작'을 눌러야 시작합니다.
  기본은 들숨 4초, 멈춤 0초, 날숨 6초입니다.
  시간은 목표가 아닙니다. 편안한 만큼만 하고 언제든 '즉시 중단'을 누르세요.
  선택형 멈춤은 0~30초입니다. 주의사항 확인 없이는 활성화하지 않습니다.
  과호흡한 뒤 참거나 힘주어 버티지 마세요. 어지럼·통증·불편감이 생기면 중단하세요.
  마이크를 사용하거나 녹음·발성 평가를 하지 않습니다. 소리는 자동 재생하지 않습니다.

허리 불편
  자세를 강제로 교정하거나 통증을 치료하는 프로그램이 아닙니다.
  편한 범위에서 자세를 바꾸고, 필요할 때 안정적인 의자를 짚고 일어나 움직이는 안내입니다.
  통증이 증가하거나 저림이 생기면 멈추세요. 부상·수술 후라면 의료진에게 확인하세요.
  허리 통증과 함께 양쪽 다리의 힘 빠짐·감각 이상, 회음부 감각 저하,
  대소변 조절 변화 등이 생기면 운동을 계속하지 말고 즉시 진료를 받으세요.

시 게임
  실제 출제 작품 149편: 한국 서정시 136편, 타고르 영어 산문시 10편, 옛 영어 노랫말 3편.
  작품 분류·언어를 고르거나 제목·작가로 검색하고 목록에서 작품을 직접 선택할 수 있습니다.
  처음 열 때와 '다른 작품 무작위'는 작품을 무작위로 고릅니다. 가능하면 직전 작품은 제외합니다.
  비어 있지 않은 한 줄 전체를 무작위 빈칸으로 보여 줍니다. 짧은 행도 출제합니다.
  '같은 작품 · 다른 줄'은 같은 작품의 다른 행을 뽑으며, 행 번호를 직접 고를 수도 있습니다.
  타고르는 산문시 원문의 문단 단위로 출제한다고 별도로 표시합니다. 영어는 영어 원문입니다.
  답을 입력하고 제출하면 내 답과 원문을 나란히 봅니다. '정답 보기'로 바로 확인할 수도 있습니다.
  띄어쓰기는 무시하지만 단어·문장부호는 원문 판본 기준으로 비교합니다.
  답안과 점수는 서버에 보내거나 디스크에 저장하지 않습니다.
  출처·판본·라이선스·검증 근거는 poetry-sources.json과 THIRD_PARTY_NOTICES.md에 있습니다.
  '최근 시·가사·노벨 작품' 탭의 공식 감상 링크 9개는 외부 브라우저로만 엽니다.
  최근 시·가사의 저작권 전문은 앱에 복제하거나 빈칸 문제로 사용하지 않습니다.
  감상 링크는 2026-11-09 확인한 고정 선별 목록이며 실시간 자동 갱신되지 않습니다.

안무
  공식 채널의 원본 연습영상에 연결합니다. 영상을 내려받거나 재배포하지 않습니다.
  사용자가 영상을 누를 때만 YouTube에 연결합니다. 인터넷 연결이 필요합니다.
  영상 재생·임베드 허용 여부는 YouTube와 게시자가 관리합니다.
  서서 하는 원본 안무와 의자 운동은 다릅니다. 충분한 공간을 확보하세요.
  통증이 있으면 점프·깊은 굽힘·비틀기를 따라 하지 말고 저강도 주제로 바꾸세요.

개인정보와 저장
  운동 그림·시 게임·알림 설정은 로컬에서 동작합니다. 로그인·계정·마이크·카메라가 없습니다.
  설정 위치: %LOCALAPPDATA%\DeskHooker\settings.json
  WebView2 로컬 프로필: %LOCALAPPDATA%\DeskHooker\WebView2
  로그인 자동 실행을 선택한 경우에만 현재 사용자 Run 레지스트리에 DeskHooker.Teum 값을 씁니다.
  다른 프로그램의 시작 설정은 변경하지 않습니다. 관리자 권한이 필요하지 않습니다.
  UI 테스트는 별도의 DeskHooker-Test 폴더를 사용하며 실제 설정이나 시작 등록을 변경하지 않습니다.

파일 구성과 이동
  DeskHooker.exe, app.html/app.css/app.js/app-core.js, games-content.js, themes-data.js,
  poetry-data.js, poetry-reading.js, poetry.css, poetry-sources.json, THIRD_PARTY_NOTICES.md,
  themes.json, 원본 GIF, themes 폴더, WebView2 DLL들을 같은 폴더 구조로 유지하세요.
  이 폴더 전체를 옮길 수 있습니다. 자동 시작을 켠 뒤 옮겼다면 새 위치에서 자동 시작을 다시 설정하세요.
  app.html을 브라우저에서 직접 열 수도 있지만 이는 미리보기입니다.
  HTML 창을 닫은 뒤에도 동작하는 전체 화면 반복 알림은 DeskHooker.exe를 사용해야 합니다.

개발·검증
  소스: ReminderCore.cs, DeskHooker.cs, app-core.js, app.js
  Windows .NET Framework 4.8 계열과 Microsoft Edge WebView2 Runtime이 필요합니다.
  UI는 WebView2의 로컬 가상 호스트 teum.local로 파일을 읽으며 외부 웹서버는 없습니다.
  WebView2 SDK: Microsoft.Web.WebView2 1.0.4314.35 (공식 NuGet 배포)
  빌드: powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\work\desk-stretch\build.ps1
  UI 테스트 포함 빌드: 위 명령 뒤에 -Test 추가
  예약 로직: test-core.ps1
  시 게임·호흡·출처·전체 원문 검증: node --test tests/*.test.cjs
  테스트 결과 및 실제 렌더 캡처: tests\ui\
