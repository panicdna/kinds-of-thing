# 커뮤니티 공유 쉼

틈 앱의 "03 어떤 작은 쉼이 필요하세요?" 타일에 나타나는, 다른 사람이 공유한 쉼입니다.
이 폴더의 `*.json` 파일 하나가 타일 하나입니다. 앱이 실행 중일 때 약 10분마다(또는 "지금 동기화" 버튼으로) 이 폴더를 읽어 목록에 추가합니다.

## 올리는 방법

앱의 03번 구역 아래 **"내 쉼 공유하기"** 에서 내용을 쓰고 **GitHub에 올리기**를 누르면, 이 폴더에 새 파일을 만드는 GitHub 화면이 미리 채워져 열립니다. GitHub 로그인 후 제안(Pull Request)을 보내면 저장소 관리자가 확인하고 병합합니다. 병합되면 모든 사용자의 앱에 나타납니다.

## 파일 형식 (`schema` 1)

```json
{
  "schema": 1,
  "id": "u-neck-reset",
  "name": "목 풀기 한 번",
  "summary": "한 줄 설명 (60자 이하)",
  "instructions": ["첫 동작 (60자 이하)", "둘째 동작"],
  "safety": "주의사항 (150자 이하)",
  "author": "표시할 이름 (선택, 20자 이하)"
}
```

| 항목 | 규칙 |
| --- | --- |
| `id` | 영소문자·숫자·`-`, 3~40자, 파일 이름과 같게 (`<id>.json`) |
| `name` | 1~30자 |
| `summary` | 1~60자 |
| `instructions` | 1~6개, 각 1~60자 |
| `safety` | 1~150자, 필수 |
| `author` | 선택, 20자 이하 |

## 지켜야 할 것

- 글자만 허용합니다. HTML 태그(`<`, `>`), 링크(`://`), 제어문자는 앱이 거부합니다.
- 치료·진단·효능을 주장하지 마세요. 통증이 생기면 중단하라는 안내를 `safety`에 넣어 주세요.
- 이름·연락처 등 개인정보를 넣지 마세요. 올린 내용은 공개됩니다.
- 앱은 규칙에 어긋난 파일을 조용히 건너뜁니다. 앱 코드와 같은 규칙이 `ReminderCore.cs`(`CommunityContent`)와 `app-core.js`(`validateShare`)에 있습니다.
